# MyProjects
Projeto de sistema de criação e gerenciamento de projetos para a matéria de Programação para a Internet no **IFRN**.

[![Ferramentas do projeto](https://skillicons.dev/icons?i=mysql,ts,sequelize,express,angular,tailwind)](https://skillicons.dev)

## Como executar localmente
1. Clone o repositorio do GitHub:
```bash
git clone https://github.com/JCOAlves/MyProjects.git
```

2. Na pasta Backend, instale as dependências da API:
```bash
npm install
```

3. Ainda na pasta Backend, execute o comando `setup` para criar um arquivo .env:
```bash
npm run setup
```

4. Para rodar a API, execute o comando:
```bash
npm run start
``` 

5. Agora na pasta Frontend, instale as dependências:
```bash
npm install
```

6. Crie o arquivo de dependências do Frontend:
```bash
npm run setup
```

7. Por fim, execute o comando:
```bash
npm run start
```
